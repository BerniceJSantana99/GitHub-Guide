# Install Git on Mac

1. Open the **Terminal** app.
2. Run:

   ```bash
   xcode-select --install
   ```

3. Follow the prompts to install Apple's Command Line Tools.
4. When it finishes, check Git:

   ```bash
   git --version
   ```

If you see a version number, Git is installed.

If you already use Homebrew, you can install Git with:

```bash
brew install git
```

More options are on the [official macOS installation page](https://git-scm.com/install/mac).
