# Install Git on Linux

Open a terminal and use the command for your Linux version.

## Ubuntu or Debian

```bash
sudo apt install git
```

## Fedora

```bash
sudo dnf install git
```

## Arch Linux

```bash
sudo pacman -S git
```

Then check that Git is installed:

```bash
git --version
```

If you see a version number, Git is installed. See the [official Linux installation page](https://git-scm.com/install/linux) for other Linux versions.
