# Setting Your Name

Whenever someone is using a terminal, or creating changes, it's important to know who is doing them.
That is why it's important to ensure that Git is using the correct name to address. Fortunately, it's simple to do and only needs t>
Once you have Git installed, go ahead and open your terminal and type the following.

```text
git config --global user.name "Your Name"
```


Ensure to replace `Your Name` with the name you want displayed on your commits.
To check your name settings, simply input in the terminal:

```text
git config --global user.name
```


It is always good practice to keep this up to date.
