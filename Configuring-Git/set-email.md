# Setting Your Email

Whenever someone is using a terminal, or creating changes, it's important to know who is doing them.
That is why it's important to ensure that Git is using the correct email address to use. Fortunately, it's simple to do and only needs to be done once per device or update.
Once you have Git installed, go ahead and open your terminal and type the following.
  
```text
git config --global user.email "Your Email"
```
  
Ensure to replace `Your Email` with the one you want displayed on your commits.
It is advised to use the same email used on GitHub so that Git can connect to your correct account.
To check your email settings, simply input in the terminal:
  
```text
git config --global user.email
```
  
It is always good practice to keep this up to date.
