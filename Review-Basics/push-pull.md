# Pull and Push

These command helps keep your computer and the work done on GitHub by you or others in sync.

## Pull

Pulling essentially copies any updates that have been done in GitHub and pastes it to the local file.
Before you start working, get any new changes from GitHub:

```bash
git pull
```

## Push

Pushing posts any changes or updates done to GitHub.
Once something is ready to be commited, remember to push it out to GitHub.


```bash
git push
```

An easy routine is: `git pull`, make your change, `git add`, `git commit`, then `git push`.
