# Pulling

This command helps keep your computer and the work done on GitHub by you or others in sync.
Pulling essentially copies and informs of any updates that have been done in GitHub and pastes it into the local file you are working from.

## Pull

Before you start working, get any new changes from GitHub:

```bash
git pull
```

An easy routine is: `git pull`, make your change, `git add`, `git commit`, then `git push`.
