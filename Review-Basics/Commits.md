# Commits

A commit saves a snapshot of your work and allows you to add a message using `-m`.

```bash
git status
git add file-name.md
git commit -m "Add a short description"
```

- `git status` shows what changed.
- `git add` chooses the file to save.
- `git commit` saves the change.

Use a short message that says what you changed, such as `Corrected Syntax Errors`.
