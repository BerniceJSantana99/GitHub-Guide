# Setting Up Your Local File

In order to benefit the most from the Git and Github features, it's ideal to save everything into a dedicated folder that holds all of your GitHub projects and repositories.
Here you will clone, save, and pull/push everything you do between your device and GitHub.

## Create A Folder

First thing is first, create a folder on your device to where you will save all GitHub projects.
Ensure to name it something memmorable and easy.
Now whenever you clone a repository, you will be saving it to this folder and working from there and GitHub.
