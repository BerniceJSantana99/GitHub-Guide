# Local To Local Connection

Local to Local Connection is the same as working inside a directory on your terminal using Git.
This makes editing, working, updating, and collaborating quicker and documented.

## How To

To ensure you are working from the inside of the correct directory or locally connected, open the terminal.
Then, type `cd` (calls directory) followed by a space and the `Local Repository Folder`'s path.

```bash
cd `Path To Local Repository Folder`
```

This connects your device to your local repository or in another words, ensures you are working in the local repository using Git.
