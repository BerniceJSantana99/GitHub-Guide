# Setting Up Your Local Folder

Its important to set up a `Local Folder` to save all of your respositories that you are working on from GitHub.
This way, when a clone, push, pull, commit, add, etc. is done, the local version gets updated along with what is on GitHub.

## Where To Put It

Knowing where to place the folder makes it easy to find, locate, call, and keep track.
To create it, ensure to do so in the main local drive.

## Naming It

Using the exact name of a folder, file, link, or image is critical for functional coding.
Because of this, its important to always know the name of your `Local Folder`.
To do so, ensure to name it something:
  
 - Easy
 - Memorable
  
This will help you remember and keep track.

## Pinning It

Quickly reaching the physical `Local Folder` is just as important.
Pinning it provides the ability to do so.
For best practice, have it pinned to an easy and accessable location.
